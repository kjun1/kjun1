== Selected work

=== link:https://github.com/kjun1/mahjong-render[mahjong-render]

A Ruby gem that turns compact riichi mahjong notation into self-contained SVG.

It also provides an optional Asciidoctor block macro, so mahjong hands can be embedded directly in AsciiDoc documents without a browser, Node.js, fonts, or a network rendering service.

`notation -> parser -> tile sequence -> SVG`

The project is intentionally small, offline-capable, documented, tested, and published as a reusable library.

== How I tend to design systems

I usually start from the system boundary rather than from a specific framework or product.

* define the *purpose* and the observable output;
* make *inputs, outputs, state, responsibilities, and constraints* explicit;
* keep interfaces narrow enough that components can change independently;
* connect implementation decisions back to their requirements and rationale;
* define how the result will be *verified*, not only how it will be produced;
* automate repeatable work while keeping important decisions observable and reversible.

This applies to code, infrastructure, data pipelines, documentation, and AI-assisted workflows.
